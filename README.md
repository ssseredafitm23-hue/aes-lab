# AES Security Lab

Лабораторна робота №4–5

**Тема:** Реалізація симетричного шифрування з використанням AES.

**Дисципліна:** Прикладні аспекти програмування в системах інформаційної та кібербезпеки.

**Виконала:** Середа Стелла Станіславівна, БІКСб-1-23-4.0д.

## Мета роботи

Розробити програмне рішення для симетричного шифрування
файлів із захищеним управлінням ключами, перевіркою
цілісності, журналюванням та оцінюванням продуктивності.

## Реалізовані можливості

- AES-256-CBC із HMAC-SHA256 та PKCS7.
- AES-256-GCM із вбудованою автентифікацією.
- PBKDF2-HMAC-SHA256: 600 000 ітерацій.
- Випадковий 128-бітний salt.
- Окремі ключі AES та HMAC.
- Заборона повторного шифрування одним ключем.
- Захищене локальне сховище метаданих.
- Динамічна зміна режиму шифрування.
- Автоматичне визначення режиму при дешифруванні.
- Автентифікація заголовка та шифртексту.
- Захист від перезапису файлів.
- Структуроване журналювання JSONL.
- Виявлення повторюваних помилок автентифікації.
- Автоматизовані вимірювання CPU, RAM та швидкості.
- Автоматизоване тестування і демонстрація підміни.

## Встановлення

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
mkdir -p data logs outputs
```

## Запуск

```bash
python aes_cli.py --help
python aes_cli.py shell
```

Приклад команд інтерактивного режиму:

```text
key new --label example-gcm
key list
mode gcm
enc --in data/sample.txt --out outputs/example.enc --label example-gcm
dec --in outputs/example.enc --out outputs/example.dec
settings
logs
exit
```

Пароль вводиться приховано. Для кожної нової операції
шифрування необхідно створити новий ключ.

Доступні режими: cbc та gcm.
Режим за замовчуванням: gcm.

## Криптографічні параметри

| Параметр | CBC-HMAC | GCM |
|---|---|---|
| Ключ AES | 256 біт | 256 біт |
| Блок AES | 128 біт | 128 біт |
| IV / nonce | 16 байтів | 12 байтів |
| Padding | PKCS7 | Відсутній |
| Автентифікація | HMAC-SHA256 | GCM tag |
| Тег | 32 байти | 16 байтів |

IV, nonce та salt генеруються автоматично.
Розмір блоку AES фіксований. Padding визначається режимом.

Проєкт призначений для навчального використання.

аудит безпеки.

не публікуються у репозиторії.
